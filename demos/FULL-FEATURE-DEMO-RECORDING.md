# 完整功能演示 · 录屏步骤

面向路演 / 评审的**一条龙录屏脚本**（桌面 live 或 http-live）。总时长建议 **10–14 分钟**；可按「精简轨」砍到 ~7 分钟。  
口播对齐 [ROADSHOW](ROADSHOW.md)。**全程勿露出 Key / Token / `.env`。**  
任务/MCP/导回主线亦可对照 [RECORDING-GUIDE](RECORDING-GUIDE.md)（偏「真实编码任务」镜头）。

相关短片：成功态 60s → [B6-SUCCESS-DEMO](B6-SUCCESS-DEMO.md)；扩权细测 → [permission-live-test](permission-live-test.md)。

---

## 0. 开录前（不入镜，约 5–10 分钟）

### 环境

| 项 | 要求 |
|---|---|
| 表面 | 优先 `./scripts/dev-desktop.sh` 或 Release `.app`；亦可 `go run ./scripts/cmd/http-live-serve`（顶栏须写「本机 live」） |
| 隔离 | 侧栏 **隔离就绪**（Seatbelt 即可；Docker 作可选加分镜，见 §8） |
| 工作区 | `demos/workspace` **绝对路径**（`python3 -c "import os; print(os.path.realpath('demos/workspace'))"`） |
| 模型 | 至少 1 个已连账号；输入框无残留 Key |
| Agent CLI | 本机 Claude / Codex / dsh 至少一种 Detect 绿灯（向导第一步会检） |
| 网络 | 能打到模型 Origin；MCP 演示可选 Context7 或预置「本机时间」 |
| 录屏 | 全屏 App 窗口；分辨率固定；关通知；缩放 100% |

### 设置（开录前配好）

1. **挂载默认**：安全副本（clone）— 导回镜依赖此  
2. **安全档位**：standard（或你们演示常用档）  
3. **演示开关**：勾选「启用扩权/阻拦演示工具」→ **保存后必须新建会话** 才注入 `harbor_demo_ask`  
4. （可选）主题浅色、字体够大，便于投影  

### 素材备好（剪切板 / 备忘）

| 用途 | 内容 |
|---|---|
| 短任务 | `列出当前工作区根目录文件名，用一句话说明。` |
| 写文件任务 | `在工作区根目录创建或覆盖 hello.txt，写入一行 harbor-demo-ok，然后用一句话确认。` |
| 导回任务 | 同 [B6](B6-SUCCESS-DEMO.md)：`创建 SYNCBACK_DEMO.md，写入 harbor-syncback-ok…` |
| 扩权 | 整段粘贴 `demos/workspace/EXPAND-TASK.txt` |
| 阻拦 | 整段粘贴 `demos/workspace/BLOCK-TASK.txt` |

### 录屏工具建议

- QuickTime / OBS；系统音频关或极低  
- 分镜可后期拼接；每段开头留 1s 静帧便于剪

## 2. 逐镜操作（可对着念）

### A · 开场 + HOME（40s）

1. 打开 App，停在 **HOME 会话中心**  
2. 指侧栏：**隔离就绪**（勿出现阻断页）  
3. 口播：

> Agent Harbor：本机跑 Agent 时，密钥留在本机、出站走 Gate、工作区默认同副本。

4. 指顶栏徽章（Seatbelt / Docker）一闪即可  

**通过画面**：有会话列表或空态引导；无 Key 明文。

---

### B · 模型页 · Key 本机（60s）

**已有账号（推荐录屏时）**

1. 侧栏 → **模型**  
2. 指列表：仅显示名 / Host / 模型引用  
3. 点「添加」打开表单 → **不要粘贴真 Key 入镜**；可指空输入框说「提交后清空」  
4. 口播：Keychain fail-closed；沙箱里只有 Sentinel  

**从零演示（另录一条可剪进）**

1. 显示名 + Origin + 协议勾选（Messages→Claude/dsh；Responses→Codex）+ Agent 勾选  
2. 粘贴 Key（后期马赛克，或切摄像头）→ 连接  
3. 成功后：**输入框清空**、列表多一行引用  

**通过画面**：`04-models-saved` 同类；无 Key 残留。

---

### C · 工具 · MCP（50s）

1. 侧栏 → **工具**  
2. 勾选预置（本机时间 / filesystem / Context7）→ 添加；或展示已连接项  
3. 口播一句边界：

> 我们保证的是凭据不进沙箱的机制，外加兼容清单——不是所有主流 MCP 开箱。

4. 勿展开失败重试；失败就剪掉本段  

---

### D · 向导开跑 + 对话（90s）

1. HOME → **新会话**  
2. 向导逐步：  
   - 工作区 = `demos/workspace` 绝对路径  
   - **安全副本（clone）** 勾选/默认  
   - Agent（与模型匹配）→ 模型账号  
   - 工具：可选已挂 MCP  
3. 指 CLI 检测绿灯 → **开始**  
4. provisioning → **running**  
5. 粘贴短任务（列目录）→ 等真实助手输出  
6. 口播：

> 这是沙箱里的真 Agent CLI，不是 mock 字幕。

**卡壳处理**：超时 / 工具错误也如实留 3–5s（真实报错加分），再发下一轮短问；不要现场改配置超 20s。

**通过画面**：边界条可见；有 assistant 文本或中文错误提示。

---

### E · 阻拦（80s）

前置：本会话已开（`harbor_demo_blocked` Gate 始终可注入；与 ask 开关无关）。

1. 工作台输入框粘贴 **`BLOCK-TASK.txt` 全文** → 发送  
2. 期望：调用失败；**无**三选一 Modal  
3. 打开活动 / 侧栏进 **记录 → 阻拦**：出现 `denied`  
4. 口播：

> 白名单外直接挡；不是弹窗让你一键全网。

**通过画面**：记录·阻拦有条目；工作台无扩权 Modal。

---

### F · 扩权三选一 + 撤销（100s）

前置：设置已勾选演示工具且 **本会话是勾选后新建的**。

1. 粘贴 **`EXPAND-TASK.txt` 全文** → 发送  
2. 弹出 Modal：拒绝 / 仅本次 / **本项目始终允许**  
3. 先点 **本项目** → toast 含主机  
4. 指工作台「已记住」或 **权限一览** 出现该主机  
5. **撤销**该记住项 → 再贴一次 EXPAND-TASK → **应再弹**  
6. 口播：

> 三选一，没有全网放行；本项目可跨重启，但你随时能撤销。

（可选加镜）工作台按钮「请求扩权」走 once / deny 各一次——时间紧可剪掉。

**通过画面**：Modal 特写（对照截图 `11`）；撤销后再弹。

---

### G · 副本写文件 + 导回（90s）

1. 确认挂载为 **clone**（边界条 / 会话信息）  
2. 发送导回任务（创建 `SYNCBACK_DEMO.md` 或覆盖 `hello.txt`）  
3. 停一下：打开**源目录**访达/终端——强调文件**尚未**或与副本不一致（若 Agent 只写了副本）  
4. 工作台 → **停止**（等 stopped）  
5. **导回原文件夹** → 确认弹窗 → toast 含源路径  
6. 切源目录：文件出现 / `grep harbor-syncback-ok` 命中  
7. 口播：

> 默认在副本改；你确认才写回源文件夹。

**通过画面**：toast + 源目录文件；对照 [B6](B6-SUCCESS-DEMO.md)。

---

### H · 记录 · 用量 / 计量（70s）

1. 侧栏 → **记录**  
2. **用量**：本机汇总 → 扫一眼按会话 / 阻拦相关数字  
3. **计量**：数量 Tab → 分模型时序柱 → **鼠标悬停**出 tip  
4. 展开参考单价（可先有一条 CNY）→ 切 **价格** Tab 一闪  
5. 口播：

> 用量本机聚合、按模型可对单价；不外传，不是官方账单。

**无真实 token 时**：用事先跑过的会话，或浏览器 `?shotSeed=1` 只作 UI 样张并口播「样张非账单」。

---

### I · 设置与权限一览（60s）

1. **设置**：指 Agent 能力边界文案、CLI 检测、安全档位、clone 默认  
2. 工作台或设置打开 **权限一览** / 网络安全记住表  
3. 口播：档位种子主机 + 用户扩权主机；可撤销  

勿在此段改隔离后端除非接 §J。

---

### J · （可选）Docker 隔离（60s）

仅当本机 Docker/Colima 已就绪、能 30s 内切到「隔离就绪」：

1. 设置 → 隔离后端 **Docker** → 引擎来源 → 保存  
2. **重启应用使生效** → 回来后顶栏 Docker + 侧栏就绪  
3. 口播：同一产品面换隔离后端；P2 证据在仓库 demos/evidence  

失败则整段删除，不要录「UNIMPLEMENTED」长镜当卖点。

---

### K · 收束（40s）

停在 HOME 或记录页，口播三句：

1. **做成了**：本机密钥、隔离执行、Gate 扩权、副本导回、本机计量  
2. **边界**：未公证；MCP=机制+清单；陌生机首跑不声称  
3. **工程**：测试闸门与发版门禁约束交付（可闪 CI / README badge，勿念 log）  

黑场结束。
